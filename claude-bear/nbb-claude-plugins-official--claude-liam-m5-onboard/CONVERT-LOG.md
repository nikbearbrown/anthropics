## Judgment calls

1. **BCRY unchanged.** The source carry-out is already a Teardown-native line — mechanism named (the four stages), scope limit named (the one exception), design read named (no flag replaces a thumb). `WantQuote`'s on-screen text IS the quote, so any narration change forces a quote change and re-renders the beat for no register gain. Kept as-is; `sparkLine: "Every stage but one."` already sings.
2. **Colors kept humanitarians-cream (`#F3EBDD` / `#2F2A26` / `#E4572E`).** Metadata says `palette: teardown` but every reference nbb reel in `claude-bear/` (e.g. `nbb-claude-basics--screenshot-prompt-caching`) leaves the underlying shot/graphic colors as the humanitarians tokens under nbb metadata. Followed convention; nothing was retinted at the shot level.
3. **Manim scene names kept (`BDNB01Scene`, `BDNB02Scene`, `BDNB03Scene`).** Retinting is a downstream render concern; the shot/graphic contract stays identical so the same scenes can be re-rendered against the teardown palette without a code change.
4. **`@NikBearBrown` folder chip + outro handle.** Applied at both the metadata level (`folderLabel`, `channel_title`) and the shot-props level. Per the reference nbb reels, an nbb-audience reel never bookends with an `@HumanitariansAI` chip; the identity carrying playlist ordering is `playlist`, which is preserved.
5. **BHTF became the LLM exercise beat (no new beat_id inserted).** Reference nbb reels in this book convert BHTF in place — same slot, same `ClaudeComposerAsk` shot, `act` retitled to `LLM EXERCISE`, `llm_exercise` block added. Followed that pattern rather than inserting a new `B_LLM` beat, which would have broken the 7-beat `filled/of` count in `metadata.build`.
6. **`OutroSeries` → `OutroCTA` on BOUT.** The scaffold carried the source `OutroSeries` shape (`eyebrow` + `line`), but every reference nbb outro in `claude-bear/` uses `OutroCTA` (`line` + `handle`). Switched to `OutroCTA` for consistency with the nbb channel bookend; narration text unchanged.
7. **B00 narration lengthened to ~20s.** The source was ~14s. The source `note` on B00 stipulates 20–35 word narration + `lead_silence_s: 0.8` for a ≥9s typing window; the new narration lands in that window at ~48 words (comfortably above the floor). Adjusted `estimated_duration_s` accordingly so audio generation sizes right.
