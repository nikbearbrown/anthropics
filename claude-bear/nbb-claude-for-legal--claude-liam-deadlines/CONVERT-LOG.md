## Judgement calls

1. **Two-beat outro merged to one.** The nbb SKILL.md says "outro is the LAST
   beat" — singular. The reference fully-converted reel
   (`nbb-books--claude-liam-data`) uses a single `OutroCTA` beat with a
   compressed "Claude, [Title] — the [thing]. Liam, in for Bear." line and
   `@NikBearBrown` handle. Followed that pattern rather than keeping
   `OutroSeries` + `OutroCTA` as two beats, because otherwise the LLM exercise
   would land third-to-last, not second-to-last.

2. **Cold-open visual left alone.** The `BrutalistHesitantWriter` props
   (colors, seed, `bg: #F3EBDD` cream, `accent: #E4572E` HAI orange) come from
   the hai-fellows source. `brand_variant.py` set the sheet-level `palette` to
   `teardown` and `ground` to the HAI cream `#F3EBDD`; the writer scene reads
   its own `bg`/`ink`/`accent` from props, not from the sheet palette. Not
   retinting: the palette swap is a sheet-level metadata claim, and touching
   the cold-open props risks breaking the seed-locked hesitation timing that
   the source `note` field guards. If the render comes back visibly HAI-cream
   under the NBB label, that's a follow-up palette pass on the props, not
   something to guess at here.

3. **`brand: hai-fellows`, `style_preset: humanitarians`, `ground: #F3EBDD`,
   `gate_h` note preserved.** These came from the scaffold and describe the
   source lineage; the completed reference reel keeps analogous source-lineage
   fields. Not scrubbing them — the `audience: NikBearBrown` +
   `palette: teardown` + `folderLabel: @NikBearBrown` fields carry the NBB
   assertion.

4. **LLM exercise `estimated_duration_s: 42`.** The narration runs long (three
   full sentences of prompt-recitation + a two-part Go deeper). Matches the
   reference reel's LLM exercise beat (`estimated_duration_s: 34` for a
   similarly-shaped prompt). Real duration is generated by
   `generate_audio_kokoro.py` at render time; the estimate is a hint, not a
   contract.
