# Agent Skills for K-12 Teachers Video Ideas

## Candidate 01 — Why below-level students need to encounter the same hard cases, just with different scaffolds

- Source: `plugin/skills/k12-lesson-differentiation/references/math.md`
- Topic: Preserving cognitive demand across differentiated tiers
- Hook: When you differentiate for below-level students, you remove the hard part — but that's exactly the part they most need to encounter with scaffolds.
- Key case: A 5th grade division lesson. The hard case: 23 apples, 6 baskets — how many per basket, and what about the leftover? You're tempted to give below-level students only even divisions. That removes the standard's cognitive demand.
- The Question: If below-level students encounter only easy instances of a problem, how will they ever develop flexibility to handle hard ones? What happens when they hit the hard case on the assessment for the first time?
- Core idea: All tiers encounter the same hard case, entered through different representations. Below-level students solidify the prerequisite concept via a visual model (arrays, with leftovers circled), then apply that model to the hard case itself — not a simplified version of the problem.
- Visual object: A division-with-remainder problem shown three ways stacked: (1) array diagram with leftover items circled, (2) symbolic division notation, (3) context interpretation ("groups of ___ with ___ left").
- Manim move: scan
- Example seed: "Divide 17 by 5. Below: draw 17 objects in groups of 5, count the groups, circle the leftovers. At: 17 ÷ 5 = 3 R2. Explain: 'Each friend gets 3 apples, 2 left over.' Above: Why must the remainder always be less than the divisor?"
- Length band: 2–3 min
- Still lanes: c2v (objects → array → notation), raster
- Prerequisites: basic multiplication and division
- Exclusions: don't cover specific visual-model teaching; don't address the full rubric criteria; don't dive into algebra
- Score: 8/10

## Candidate 02 — Why representation layers let you scaffold toward abstract without reducing the cognitive task

- Source: `plugin/skills/k12-lesson-differentiation/references/math.md`
- Topic: CRA progression as differentiation scaffold sequence
- Hook: Below-level students need the same problem as everyone else — but accessed through manipulatives first, building toward abstract symbols.
- Key case: Adding fractions with unlike denominators (1/3 + 1/2). Below-level students use fraction circles to model each amount, then combine. At-level students draw a tape diagram. Above-level students work purely symbolically and explain why the procedure works.
- The Question: How do you scaffold a grade-level problem for below-level students without handing them an easier task? Where do they enter the representation progression?
- Core idea: The Concrete-Representational-Abstract (CRA) model provides the scaffold sequence. All tiers solve the same problem but enter the representation ladder at different rungs. Below climbs from concrete (manipulatives); At starts at representational (visual diagrams); Above begins at abstract (symbols) and extends to generalization or structural insight.
- Visual object: A single fraction-addition problem shown three ways stacked vertically: (1) physical fraction circles or blocks, (2) a tape diagram, (3) the symbolic equation and procedural explanation.
- Manim move: accumulate
- Example seed: "Add 1/3 + 1/2. Below: arrange fraction circles to model one-third and one-half, push them together to see the sum is 5/6. At: draw a tape diagram divided into thirds and halves. Above: solve symbolically (1/3 + 1/2 = 2/6 + 3/6 = 5/6) and explain why the common-denominator procedure is necessary."
- Length band: 2–3 min
- Still lanes: c2v (concrete objects → visual → symbolic), raster with overlay
- Prerequisites: fractions, basic addition
- Exclusions: don't cover manipulative-based instruction methods; don't dive into prerequisite-standard alignment; don't address algebra
- Score: 8/10

## Candidate 03 — Why an easier text actually closes off grade-level engagement rather than opening it

- Source: `plugin/skills/k12-lesson-differentiation/references/ela.md`
- Topic: Access scaffolding versus text substitution in reading differentiation
- Hook: Your struggling reader needs to engage with the same grade-level text as everyone else — but with different support structures, not an easier text.
- Key case: A 7th grade class reads a complex passage on civil rights. Below-level students read the identical passage but with chunked-reading guides ("As you read this paragraph, mark: the main idea, one piece of evidence, one unknown word"). At-level students read it unscaffolded. Above-level students read it and compare to a related historical text.
- The Question: If a student struggles to access a grade-level text, wouldn't giving them an easier text help them succeed? Why is that actually counterproductive, and what mechanism works instead?
- Core idea: Access scaffolds — annotation guides, pre-taught vocabulary, chunked-reading cues, sentence supports — preserve grade-level text engagement while building comprehension toward independence. The text itself is constant; what changes is the structure scaffolding access. The progression runs from heavily scaffolded (Below) to unscaffolded (At) to enhanced/analytical (Above).
- Visual object: The same text passage shown in two versions side-by-side: one with dense scaffolding overlaid (annotation prompts in margins, vocabulary callouts, reading-chunk markers), one clean (At-level).
- Manim move: split
- Example seed: "A paragraph on the First Amendment. Below: 'As you read, mark (circle) main idea, (underline) evidence, (?) unknown word. Vocabulary: amendment, ratified, rights.' At: 'Identify the author's central argument.' Above: 'Compare this to the Second Amendment passage — what's similar in how each author structures the argument?'"
- Length band: 2–3 min
- Still lanes: c2v (text + annotation), raster
- Prerequisites: annotation, basic reading comprehension
- Exclusions: don't cover specific annotation techniques; don't address vocabulary pre-teaching methods; don't cover the full rubric framework; don't address writing differentiation
- Score: 7/10

## Candidate 04 — Why comprehension scaffolds fail when the real barrier is reading fluency, not comprehension

- Source: `plugin/skills/k12-lesson-differentiation/references/ela.md`
- Topic: Fluency as a hard prerequisite in grades 3–5
- Hook: Your comprehension scaffolds aren't working — but you might be solving the wrong problem entirely.
- Key case: A 3rd grader reads "The cat sat on the mat" slowly, sounding out every word, then can't answer "Where was the cat?" You add a graphic organizer and pre-taught vocabulary. Nothing changes. The real barrier is reading fluency (automatic, fast decoding), not comprehension capacity. Comprehension scaffolds cannot compensate for a fluency ceiling.
- The Question: When comprehension supports fail, what hidden prerequisite are you missing? How do you tell whether a student's gap is in comprehension (what they understand) or fluency (how fast they read)?
- Core idea: At grades 3–5, fluency (automatic, accurate, fast reading) is a hard prerequisite for comprehension. When decoding consumes working memory, no cognitive resources remain for comprehension. The mechanism is working-memory load: low fluency = decoding taxes working memory → no capacity for meaning-making. The fix is separate fluency intervention (outside this lesson); an appropriate immediate access bridge is read-aloud or partner reading.
- Visual object: A working-memory capacity bar shown in two scenarios: one where decoding consumes most available memory (low fluency), leaving little for comprehension; another where decoding is automatic (high fluency), leaving ample room for comprehension work.
- Manim move: slosh
- Example seed: "A 3rd grader reads 'She discovered that patterns in nature can help predict weather.' With low fluency (slow decoding), working memory is consumed by sounding out words, leaving no capacity for meaning. With high fluency (automatic decoding), the same sentence frees working memory for understanding. While fluency intervention happens separately, read-aloud serves as a bridge."
- Length band: 2–3 min
- Still lanes: geo (working-memory bar), c2v (student decoding load), raster
- Prerequisites: working memory, K–5 reading development
- Exclusions: don't cover phonics or fluency-building methods; don't address dyslexia or serious reading disabilities; don't cover comprehension-strategy instruction
- Score: 6/10

## Candidate 05 — Why math prerequisites can't be scaffolded around — they have to be routed through

- Source: `plugin/skills/k12-lesson-differentiation/references/math.md`
- Topic: Math knowledge compounding and the prerequisite-gap mechanism
- Hook: In ELA and science, scaffolding grade-level content works for below-level students. In math, if the prerequisite concept is missing, no scaffold for the grade-level concept will catch.
- Key case: A 6th grader meets ratio reasoning. The teacher adds double number lines, ratio tables, sentence supports. Nothing moves. The real gap is 5th-grade fraction equivalence — the prerequisite. Scaffolding ratio notation has nothing to attach to.
- The Question: Why does a well-designed scaffold for the grade-level concept sometimes completely fail to move a student? What makes math structurally different from ELA in this regard?
- Core idea: Math knowledge compounds — each concept sits directly on a prior concept in a dependency chain. A missing prerequisite leaves the grade-level scaffold floating. The below-tier scaffold must route through the prerequisite first, building from that prior concept up to the grade-level task, not simplify the grade-level task itself.
- Visual object: A vertical tower of math concept blocks, each resting on the one below. One block (prerequisite) is missing; the grade-level block above it hangs with no support.
- Manim move: accumulate (tower builds), then transform (gap block removed, upper block falls)
- Example seed: "5th grade: fraction equivalence (2/4 = 1/2). 6th grade: ratio reasoning (2:4 = 1:2). A below-level 6th grader without fraction equivalence cannot absorb ratio scaffolds. The below-tier scaffold must first reactivate fraction equivalence via a tape diagram, then bridge to ratio notation — not simplify the ratio problem."
- Length band: 2–3 min
- Still lanes: geo (tower diagram with missing block), c2v (fraction → ratio bridge)
- Prerequisites: basic fractions, multiplication
- Exclusions: don't cover the CCSS fallback chain or KG lookup procedure; don't address individual student diagnosis or intervention planning; don't extend to algebra
- Score: 8/10

## Candidate 06 — Why simplifying the writing task for below-level students removes the standard instead of scaffolding it

- Source: `plugin/skills/k12-lesson-differentiation/references/ela.md`
- Topic: Writing purpose preservation across differentiation tiers
- Hook: The most tempting differentiation move for writing — give below-level students a simpler task — actually replaces the standard rather than scaffolding it.
- Key case: A 6th grade argumentative writing lesson. Prompt: "Should students have homework? Write a claim, provide two reasons, and use evidence from the text." The below-level version becomes: "Summarize what the author says about homework." This looks like reducing complexity. It isn't — it substitutes an informational writing task for an argumentative one. Below-level students are now working on a different standard entirely.
- The Question: When you reduce writing complexity for below-level students, at what point does "simpler" become "different standard"? What's on either side of that line?
- Core idea: Writing purpose — the genre, claim structure, and standard — must be constant across all tiers. What legitimately varies is structural support: sentence frames, graphic organizers, paragraph scaffolds. Changing argument to summary changes the standard, not the difficulty. The scaffold must preserve the task type while structuring the student's thinking.
- Visual object: Two below-level versions of the same assignment shown side by side: one with sentence frames ("My claim is ____. One reason is ____.") that preserves the argumentative standard; one with a summary prompt that substitutes a different standard. A label marks which path preserves the standard.
- Manim move: split (one original prompt forks into two paths: structural scaffold vs task substitution)
- Example seed: "Argument prompt: 'Should recess be longer?' Scaffold path (preserves standard): 'My claim is ______. One reason is ______. Evidence: ______.' Substitution path (drops standard): 'Write 3 things the text says about recess.' The first keeps students in argumentative writing with a frame. The second moves them to informational summary — a different standard."
- Length band: 2–3 min
- Still lanes: c2v (prompt → two scaffold versions), raster (side-by-side task comparison)
- Prerequisites: basic writing, claim vs summary distinction
- Exclusions: don't cover sentence frame design in depth; don't address multi-paragraph structures or rubric scoring; don't extend to reading differentiation
- Score: 8/10
