# ACTS.md — Your First Prompts (Film 2 of 12)

**Exact title:** Your First Prompts

**Core promise:** By the end, the viewer can open the Meta AI playground,
set a spend limit, run a first prompt with the right reasoning effort, and
read the meter.

**Structure:** hook + key terms + four acts (10 body beats) + recap + your
turn + outro. 15 beats, 280 s (4m40s).

- **Hook (BIDEA):** the playground is where you meet the model.
- **Key terms (BDEFS):** Playground · Spend limit · Reasoning effort · Prompt.
- **Act 1 — The account (2 beats):** B01 attach a card, set a spend limit
  (a cap, not a deposit); B02 no $5 minimum, charged once past about a dollar.
- **Act 2 — The controls (4 beats):** B03 the four controls (model picker,
  reasoning effort, streaming, toggles); B04 the first prompt (JLPT N5
  grammar list — ask something you can judge); B05 the reasoning-effort dial
  (low → extra high, match the problem); B06 reading output like a
  practitioner (keep what earns a second look).
- **Act 3 — The meter (2 beats):** B07 what five dollars buys (his
  experience: hundreds of prompts); B08 watch the meter (tokens in/out;
  extra-high multiplies both).
- **Act 4 — The edges (2 beats):** B09 playground friction (no copy button,
  no direct image paste — honest edges); B10 when to leave the playground
  for code.
- **BVDT:** one line per act (4 lines).
- **BHTF:** set a $2 spend limit, run one prompt on something you know,
  check the answer and the cost.
- **BOUT:** "Muse, in for Bear. Thanks for watching." + teaser for Film 3
  (Muse Can See).

**Tone:** hands-on, lab-bench. The viewer should feel able to do this in the
next ten minutes. Judgments (cost experience, "cheapest lab bench") are the
instructor's, attributed.

**What this film is not:** not the models story (Film 1); not vision or
website building (Film 3); not programmatic API use (that's later films).

**Cast per act:** the playground is a browser-window card (terracotta header);
the meter is a token gauge reused in B07/B08; the effort dial is one arc
reused in B03/B05.

**Source facts:**
- Playground: dev.meta.ai / developers.meta.com; attach card, set a spend
  limit. (transcript §3)
- No $5 minimum (unlike other providers); charged once past about $1.
  (transcript §3)
- Controls: model picker (1.2 / 1.1), reasoning effort, streaming, grounded
  search toggle, JSON schema. (transcript §4)
- First prompt: JLPT N5 grammar list; ~40 grammar points back, clean
  formatting; playground has no copy feature. (transcript §4)
- Reasoning effort: low / medium / high / extra high; he runs extra high "for
  fun" and admits medium would do. (transcript §4)
- Cost experience: barely dented $100 across the course; ~$50 spent; $20–30
  or $50/month realistic for heavy use. (transcript §2)
