# ACTS.md — Structured Outputs (Film 6 of 12)

**Exact title:** Structured Outputs

**Core promise:** By the end, the viewer can make Muse return JSON that obeys
a schema — and turn that JSON into something a human can read.

**Structure:** hook + key terms + three acts (9 body beats) + recap + your
turn + outro. 14 beats, ~284 s (~4m44s).

- **Hook (BIDEA):** make the model fill in your form.
- **Key terms (BDEFS):** JSON Schema · Constraint · Rubric · Report.
- **Act 1 — The contract (3 beats):** B01 why a schema constrains reasoning,
  not just formatting; B02 the Japanese-grader rubric (score, categories,
  feedback); B03 write it once, reuse it forever.
- **Act 2 — The grader loop (4 beats):** B04 the challenge sentence; B05 the
  student's attempt (looks fine — that is the problem); B06 graded JSON comes
  back (seventy out of one hundred); B07 reading the grade like a
  practitioner.
- **Act 3 — The report (2 beats):** B08 feeding the JSON back to render an
  HTML report (the data survives the trip); B09 the 70-out-of-100 walkthrough
  — a study session became a system.
- **BVDT:** exactly 3 lines, one per act.
- **BHTF:** write one tiny schema, three fields, for something you actually
  wrote this week; ask the model to fill it.
- **BOUT:** "Muse, in for Bear. Thanks for watching." + teaser for Film 7
  (Muse in Code).

**Tone:** practitioner, exact. The film treats the schema like a tool in the
hand, not a concept on a slide — everything on screen is a card, a field,
or a number.

**What this film is not:** not a JSON Schema syntax tutorial; not the
playground story (Film 2) or the code story (Film 7); not a claim that
schemas make grading "objective" — they make it legible.

**Cast per act (one look):** white contract/schema cards with dot bullets and
field rows; terracotta accents for the score and the highlighted mistake;
blue for the report pages; the loop arrow returns in B09/B11 as a ring
around the finished report.

**Source facts:**
- Schema constrains reasoning, not just format. (transcript §8)
- Japanese-grader rubric schema: score, categories, feedback.
  (transcript §8)
- The loop: challenge → attempt → graded JSON. (transcript §8)
- Graded JSON fed back in to render an HTML report. (transcript §8)
