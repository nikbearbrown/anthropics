# Let the Code Make the Calls

**What this is.** A show-tell explainer (about 2.5 minutes) of programmatic tool calling in the Claude API, drawn as one cast. Normally each tool call is a round trip: Claude asks, your app runs the tool, and the whole result lands in Claude's context. In Anthropic's cookbook example, eight big expense results fill the context. With programmatic tool calling you add the code execution tool and mark each tool with `allowed_callers`. Claude writes one short Python script that runs in a sandbox Anthropic manages; the script calls your tools (your app still runs them), gets the results back itself, does the sums, and only the printout reaches Claude. Labels only; Liam's voice does the explaining. **Why.** Card #18 in `../show-tell-ideas.md` (Batch 2), built on Bear's overnight order of 2026-09-27. It extends #10 ("Claude Asks, Your Code Runs"), and no film covered this. **Found.** The mechanism matches the notebook and the raw live docs page. One number is shown, attributed: in the notebook's one run, total tokens fell from 110,473 to 15,919 (85.6%). The notebook's beta header, tool version and model are out of date (the live page says the feature is generally available), so the film names none. The notebook's call counts, line-item counts, dollar totals and latency contradict each other and were left out. The docs' caveat is in the film: a step-by-step chain, or a few small calls, gains little.
