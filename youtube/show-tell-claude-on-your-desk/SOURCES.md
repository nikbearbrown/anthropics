# SOURCES — show-tell-claude-on-your-desk

**What this is.** The primary sources for every claim, and how each one was read. All are in the local copy of `anthropics/claude-desktop-buddy/` (the anthropics/claude-desktop-buddy repository, mirrored in this tree), read on 2026-09-26.

1. **`README.md`** (read in full) — what the bridge is (Claude for macOS and Windows connects Claude Cowork and Claude Code to maker devices over BLE; devices display permission prompts, recent messages and other interactions; "a lightweight, opt-in API"); "Building your own device? You don't need any of the code here"; the example desk pet on ESP32 (sleeps, wakes, gets impatient, approve or deny from the device); hardware (M5StickC Plus); pairing (developer mode → Hardware Buddy → Connect); auto-reconnect; controls (A approve, B deny); the seven states (attention: LED blinks; heart: approved in under 5 s); availability (developer mode only; not an officially supported product feature).
2. **`REFERENCE.md`** (read in full) — the wire protocol: the bridge is off by default; Nordic UART Service UUIDs; one UTF-8 JSON object per line; the heartbeat snapshot (`total`, `running`, `waiting`, `msg`, `entries`, `tokens`, `tokens_today`, `prompt`; sent on change plus a 10 s keepalive); turn events; permission decisions (`{"cmd":"permission","id":…,"decision":"once"|"deny"}`); commands and acks; folder push; security and pairing (snippets and hints flow over the link; sniffable without encryption; require LE Secure Connections bonding; the 6-digit passkey; AES-CCM from then on); "Any device that can advertise the Nordic UART Service and parse newline-delimited JSON will work: Arduino, ESP32, nRF52, a Raspberry Pi with a BLE dongle."
3. **`CONTRIBUTING.md`** (read in full) — "The best contribution is a fork"; a reference implementation, "a worked example of one device"; "`REFERENCE.md` is the contract, this firmware is just one way to honor it".
4. **Firmware, skimmed** — `src/main.cpp` (the state machine `derive()`, the 12 s sleep hold after a screen wake, button A sends `"decision":"once"` and triggers hearts under 5 s, button B sends `"deny"`, the LED pulses on attention, the About page text); `src/data.h` (connection is live if a snapshot arrived in the last 30 s; `entries` parsing); `src/ble_bridge.cpp` (passkey-entry pairing, DisplayOnly, random 6-digit passkey; advertises as `Claude-XXXX`).
5. **Cast reused** from the batch's earlier show-tell films (`show-tell-inspector-says-no-first/`, `show-tell-spending-your-effort/`): the kraft/ink palette, the dark-kraft outline for small objects, the midpoint guard, the white tag, the check.
