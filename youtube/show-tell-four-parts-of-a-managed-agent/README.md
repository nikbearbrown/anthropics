# Four Parts of a Managed Agent

**What this is.** A show-tell explainer (about 2.5 minutes) of the four core parts of Claude Managed Agents, which is in beta, drawn as one cast. The agent is a white blueprint card: the model, a system prompt, tools, MCP servers and skills, made once and reused by ID, with a new card for each version. The environment is an open kraft crate: where sessions run, which packages go in, and a fence with one gap to an allowed host. Each session is a closed crate on a pad, its own fresh container, with a lamp that shows idle or running. Events are white cards riding belts: a `user.message` in, agent events out, another message to steer, an interrupt to stop. On idle the sandbox is checkpointed (a photo card) and the next message resumes it.
