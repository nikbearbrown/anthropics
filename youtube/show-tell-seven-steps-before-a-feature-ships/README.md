# Seven Steps Before a Feature Ships

**What this is.** A show-tell explainer (about 2.6 minutes) of Anthropic's `feature-dev` plugin for Claude Code and its one command, `/feature-dev`, from `claude-plugins-official/plugins/feature-dev/`. It is drawn as one cast. A long kraft corridor splits into seven rooms, and the feature ticket hops through them in order, with terracotta stop lamps over the phases that wait for you. Then one beat per phase: discovery (Claude asks, sums up, you confirm), exploration (two or three code-explorer agents trace the codebase in parallel and bring back five to ten key files each, which Claude reads), clarifying questions (the phase the command calls critical; Claude waits for your answers), architecture (two or three code-architect agents each draw one blueprint: minimal, clean or pragmatic; Claude recommends one and you pick), the build (only after you approve; to-dos tick off), quality review (three code-reviewer agents in parallel, each reporting only issues it rates 80 or above out of 100; then you choose fix now, fix later or proceed as is) and the summary. A last beat says when the plugin's README says to use it, and when not.
