**What this is.** The primary source for every claim in the film, and how it was read. **Why.** The Batch 2 brief requires fact-checking against the RAW source, not a summary. The source is a plugin folder, so every file was read raw and in full, then diffed against the raw live files on GitHub. **Found.** The local copy and the live copy are byte-identical. The README and the command file agree on the seven phases; the one real disagreement is inside the README, on the reviewer's confidence floor (below). Naming Anthropic's plugin directory is fine (the bookloop law does not apply to this batch).

**Where the files differ, and what the film does.**
- README Phase 4 says the architects are launched "with different focuses" but doesn't say in parallel; the command file says "in parallel". The film doesn't say parallel for the architects (only for explorers and reviewers, where both files agree).
- README agent section, `code-reviewer` Output: "Critical issues (confidence 75-100)" and "Important issues (confidence 50-74)". This contradicts both the README's own Focus areas line ("only reports high-confidence issues ≥80") and the agent file ("Only report issues with confidence ≥ 80"). The agent file is what runs, so the film says "eighty or above" and uses neither 75 nor 50.
- README Phase 1 lists what Claude asks without the "if feature unclear" condition; the command file makes the questions conditional ("If feature unclear, ask user for…"). The film follows the command file ("If the request is unclear").
- The README names the plugin's author; the film credits no person.
