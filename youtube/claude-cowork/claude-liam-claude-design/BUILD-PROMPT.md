# BUILD PROMPT — claude-design

## Episode concept
Claude Design is Anthropic's standalone design product living at claude.ai/design — separate from the Claude app, running on Opus 4.7, and capable of producing websites, slide decks, and animated videos from short prompts. This reel teaches viewers three quick entry points (wireframe, slide deck, animated video), then goes deeper with the advanced Cowork-to-DESIGN.md pipeline that locks in brand context before any generation runs. The closing point — taste is all you need — frames AI as a design multiplier, not a replacement: the machine does ten versions, a human picks one.

Spark card. Emphasizes the first half of the advanced workflow: Cowork extracts brand system into a single DESIGN.md file. Sub-text grounds the action: "Extract brand guidelines from any folder of assets."

**B05 — SPARK: Upload once. Always on.**
Spark card. Covers the second half of the advanced workflow: uploading DESIGN.md into Claude Design so every subsequent prompt inherits brand context. Sub-text reinforces the payoff: no repeated color/font specification.
