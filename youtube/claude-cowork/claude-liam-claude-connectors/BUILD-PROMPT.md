# BUILD PROMPT — claude-connectors

## Episode concept
Claude Connectors turn Claude into a hub that reads your real data — emails, meetings, CRM, slides, team channels — without a single copy-paste. The episode introduces the concept, tours 9 favorites, shows how to stack them, and then delivers the counterintuitive discipline: three rules for when NOT to use connectors, with the title rule ("don't leave them all on") as the central teaching.

## Beat-by-beat production notes

**B01 — ClaudeComposerAsk (0–9 s)**
Greeting "Jambo" in typing animation. Ask: "What's pending in my Gmail inbox from this week?" Answer preview: "Claude reads your actual Gmail. Zero copy-pastes." Establishes the value proposition immediately. Liam sign-in overlay bottom-left.

**B02 — SPARK: "One click. Every app." (9–18 s)**
High-level concept card. Sub-text walks through the three-step enable sequence (+ icon → Connectors → toggle). Keep it fast and practical.

**B03 — ILLUSTRATION: 9 connectors grid (18–32 s)**
Draw-on 3×3 grid. Row 1: Granola / HubSpot-Salesforce / Notion. Row 2: Microsoft 365 / Slack / Google Drive. Row 3: Gamma / Gmail / (stack tip). Each cell: connector name bold + one-line use case in smaller type. Row-by-row reveal. No logos needed at slate stage — names only.

**B04 — SPARK: "Stack the connectors." (32–40 s)**
The power move. Granola + Slack + Gmail together in one chat session. Emphasize the compound value of combining context sources.

**B05 — ILLUSTRATION: 3 rules (40–52 s)**
Numbered warning list. Large terracotta rule numbers (1, 2, 3). Rule name bold, rationale in regular weight beneath. Draw-in top-to-bottom, one rule per beat of narration. Rule 1 (tokens), Rule 2 (creative work), Rule 3 (write access).

**B06 — SPARK: "Read first. Write later." (52–61 s)**
Doubles down on Rule 3 because it's the one with real downside risk. "Most data accidents happen on day one" is the memorable line to reinforce.

**B07 — SPARK: "Build your own." (61–69 s)**
Developer-facing card. Keep it brief. Custom connector = MCP server + public URL. One sentence. Doesn't need detail at slate stage.

**B08 — HANDOFF (69–78 s)**
Three connectors only. Specific starter stack: meeting notes + email + team channel. Sequential onboarding (one per day) lowers the risk of token overload.

**B09 — OUTRO (78–86 s)**
Title in all caps. Episode title restates the core discipline. Short outro narration mirrors the beat 1 energy.
