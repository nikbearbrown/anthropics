# BUILD PROMPT — stop-writing-like-ai

## Episode concept
A teardown of negative parallelism — the "It's not X, it's Y" sentence pattern that has saturated AI-generated corporate writing. The episode names 15 shapes of the pattern, 8 additional AI tells, then delivers the practical fix: an anti-ai-writing-style.md file in the Claude Cowork folder that audits all output automatically.
