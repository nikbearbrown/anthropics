# BUILD PROMPT — claude-for-your-team

## Episode concept
A 5-day team adoption playbook for Claude. The central insight is that adoption is a sales problem, not a training problem — so you manufacture one high-impact "wow moment" (Wednesday) before touching anyone else. The playbook runs Monday (Projects) → Tuesday (Templates) → Wednesday (Wow) → Thursday (Convert the drowning colleague) → Friday (Full rollout).
