# BUILD PROMPT — claude-cowork

## Episode concept
The files-and-folders approach to Cowork was widely taught but it has two fatal flaws: folders leak stale context into live sessions, and about-me files become too painful to maintain. This reel replaces that paradigm entirely with Skills (reusable slash-command prompts that travel anywhere) and Projects (bounded persistent contexts for recurring work). It also introduces the two underrated habits that make Cowork sessions faster and higher quality: AskUserQuestion (letting Claude interview you instead of you overthinking a long prompt) and Wispr Flow (dictating instead of typing so you give more context naturally). The one-hour setup pie chart grounds the abstract advice in a concrete time commitment.
