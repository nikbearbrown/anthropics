# BUILD PROMPT — how-to-prompt

## Episode concept
Opus 4.7 is not smarter in the same way 4.6 was smarter — it is differently literal. It does exactly what you typed, which means the prompts that worked before now either overshoot or undershoot. This reel is a teardown: seven specific shifts, side-by-side before/after examples, a bonus technique for forcing maximum reasoning, and a closing call to action that is deliberately minimal (rewrite one prompt, compare one result). The register is a teardown, not a tutorial — authoritative and direct, not hand-held.
