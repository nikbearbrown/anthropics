# BUILD PROMPT — claude-skills

## Episode concept
Most people use Claude by rewriting the same instructions every single session. Skills solve that. A Skill is a saved prompt file activated by a slash command — one line to load your entire playbook. This reel walks viewers through exactly four steps to install Ruben's /how-to skill, explains why skills are portable across AI platforms (author's claim), and gives viewers three paths to build their own first skill. The episode ends by pointing them at two concrete actions: install the example skill, then immediately build their own.
