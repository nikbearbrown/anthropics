# BUILD PROMPT — claude-to-sound-like-you

## Episode concept
A philosophical teardown of personal identity as a text file. The episode argues that your voice — every tic, analogy, and avoidance — is a pattern, and patterns fit in a file. It then delivers the practical method: 100-question self-interview → compress → upload to Cowork. The resistance section (4 objections) is the emotional core — it validates the viewer's hesitation before dismantling each reason. Ends with a tight outro that holds the tension: "You are not just a text file. But you fit in one."

## Beat-by-beat production notes

**B01 — ClaudeComposerAsk (0–9 s)**
Greeting "Aloha" in typing animation. Ask: "Write this in my voice." Answer preview: "Claude sounds exactly like you — because it read your about-me file first." The ask should feel casual (not a long prompt) — the contrast makes the concept land. Liam sign-in overlay bottom-left.

**B02 — SPARK: "You're a pattern." (9–17 s)**
Reframe card. "You're just a text file" is the episode title but it's the opening provocation — the card softens it: "you're a pattern, and patterns fit in a file." This is the conceptual foundation.

**B03 — ILLUSTRATION: 3-step extraction (17–27 s)**
Draw-on horizontal flow. Step 1: icon (chat bubble) + "100 questions." Arrow. Step 2: text stack icon + "~20,000 words" (label: author's experience). Arrow. Step 3: clean file icon + "about-me.md." Left-to-right reveal, 0.5 s per step. Include a faint "2 hours" time label beneath the full flow.

**B04 — SPARK: "Compress it." (27–36 s)**
The step most people miss. The raw dump is too big for the context window. A second prompt in the same conversation compresses it. This is the key practical differentiation from just "do a long interview."

**B05 — ILLUSTRATION: 4 resistances (36–48 s)**
2×2 grid. Each cell: objection in italic (top), reframe in normal weight (bottom). Cell 1: "Feels reductive" / "It makes you compatible, not smaller." Cell 2: "Feels scary" / "Nowhere to hide = clarity." Cell 3: "Self-knowledge takes decades" / "The file forces specificity." Cell 4: "Hard to capture" / "Mystery is usually just vagueness." Reveal reading-order, 0.4 s per cell.

**B06 — SPARK: "Portable. Delegatable." (48–57 s)**
Outcomes card. The three wins: portability (any AI), delegation (give to team), consistency (stop re-deciding your voice). All from one file.

**B07 — SPARK: "Edit it. Often." (57–66 s)**
Maintenance card. Every Claude error is an edit opportunity. One line added to about-me.md fixes it forever. Connects to Reel 14 (Obsidian as the editing interface).

**B08 — SPARK: "Three tools. One file." (66–75 s)**
Tool stack card. Claude + Extended Thinking (interview) + Wispr Flow (voice dictation) + Obsidian (editing). Deliberately short — the tools aren't the point, the output is.

**B09 — HANDOFF (75–84 s)**
Action is specific and bounded: block two hours, run the interview, compress, upload, run one writing task. The "compare before and after" line gives the viewer a built-in proof moment.

**B10 — OUTRO (84–92 s)**
"You are not just a text file. But you fit in one." This outro narration deliberately echoes the source author's own title. The outro card shows the episode title in all caps to make the tension visible: YOU'RE JUST A TEXT FILE.
