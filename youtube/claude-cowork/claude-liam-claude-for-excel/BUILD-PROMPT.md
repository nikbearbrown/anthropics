# BUILD PROMPT — claude-for-excel

## Episode concept
Claude Cowork is not an Excel editor — it is a spreadsheet creator. That distinction is the reel's spine. Starting from scratch, Cowork builds the full file, exports it to Google Sheets via a single Drive click, and from there a ChatGPT extension handles AI-powered edits. One magic phrase — "top ten assumptions to sanity check before execution" — keeps the human in the driver's seat throughout. The reel closes with an honest mention of Shortcut.ai for viewers whose full-time work is spreadsheet-heavy.

## Beat-by-beat production notes

**B01 — COMPOSER_ASK (cold open)**
Show Claude.ai or Claude desktop Composer interface. The ask is typed in. "Salam" as first word (Azerbaijani/Arabic greeting). Liam badge bottom-left. Answer preview fades in referencing Cowork.

**B02 — SPARK: Create, don't edit.**
Spark card establishing the core framing: Cowork is for creation. Sub line is a quick three-step orientation: Cowork tab → connect Drive → select folder.

**B03 — SPARK: Top ten assumptions.**
This is the key technique beat. The card isolates the exact phrase. Narration explains why it matters: it keeps the human approving logic, not just receiving output.

**B04 — ILLUSTRATION: Three-tool workflow**
Draw-on animation. Three boxes in a horizontal row connected by terracotta arrows. Labels: "Cowork / create", "Google Sheets / host & share", "ChatGPT extension / edit". Clean, flat design. No screenshots. This beat carries the workflow overview so the viewer sees the full picture before the detail beats.

**B05 — SPARK: ChatGPT edits. Cowork creates.**
Reinforces the division of labor. Narration uses the concrete example from source: changing the bull scenario in an Assumptions tab. Keeps it practical.

**B06 — SPARK: Shortcut.ai — full-time option.**
Honest acknowledgment of an alternative for power users. Framed as an expansion, not a replacement for the core workflow.

**B07 — HANDOFF**
Concrete three-step viewer action: open Cowork, use the sanity-check phrase, export to Sheets. The third micro-step (try ChatGPT extension on one cell) gives a complete loop to close.

**B08 — OUTRO**
Three-word workflow summary in narration: Cowork creates. Sheets hosts. ChatGPT edits. Episode title poster in caps. Liam sign-off.
