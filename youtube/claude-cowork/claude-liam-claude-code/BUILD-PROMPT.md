# BUILD PROMPT — claude-code

## Episode concept
Claude Code is the mode developers talk about constantly, but non-coders avoid because it sounds technical. This reel makes it approachable by stripping it down to two legitimate use cases (mockup for devs, personal tool), a clean seven-step setup, two styling shortcuts (DESIGN.md and shadcn/ui), and a clear routing diagram for when you should use Artifacts, Cowork, or ChatGPT instead. The episode ends with a direct, doable action: find one boring job and give Code thirty minutes.
