# CARRY-OUT — GATE C

Written before any other narration. Every beat in this reel exists to make this
sentence survivable.

## The line

> **The watermark says Claude probably touched this text. It never says a human
> didn't write it.**

## The wrong guess it defeats

Two, stacked:

1. **Mechanism-level:** "it hides special characters in the text." It does not.
   Nothing is added; there are no hidden characters. The mark *is* the word choices.
2. **Meaning-level (the one that matters):** "a detected watermark proves the text
   is AI-written." It proves involvement, not authorship. Anthropic's own wording:
   it "cannot distinguish 'Claude wrote this' from 'Claude heavily edited this.'"

## The secondhand test

*If someone repeats only this sentence in a meeting next week, is it still true?*

Yes. It survives being repeated by a teacher deciding whether a student cheated, by
an editor checking a submission, and by a manager reading a report — which are
exactly the rooms where the wrong version of this sentence does damage.

## What it deliberately does not say

- Not "the watermark is unreliable." It is reliable at what it measures.
- Not "you can beat it." Evasion is not the subject.
- Not a summary of how watermarking works. It compresses the **distinction**, not the topic.
