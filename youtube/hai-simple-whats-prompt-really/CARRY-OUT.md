# CARRY-OUT — What's a prompt, really?

## The carry-out line

> A prompt is everything the model can see — not just what you typed, but the whole conversation and any instructions that were set before you arrived.

## Test

If someone repeats only this line in a meeting next week, is it still true?
Yes: it correctly separates what a newcomer thinks a prompt is (just the message they typed) from what it actually is (the full assembled block).

## Wrong guess this defeats

> "A prompt is just what you type into the chat box — like a command."

The beat that breaks this: B04. The conversation carries forward across turns, which can't be true if only the latest message were sent.
