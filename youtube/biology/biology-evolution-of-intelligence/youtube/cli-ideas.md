## Candidate 02 — "Build the Prediction Error Learning Simulator with Claude"
- Source: biology-evolution-of-intelligence/chapters/04-learning-and-memory.md + LLM Exercise
- Lane: BUILD (Claude Code)
- Hook: Pavlov's dogs showed that what updates in learning is not the response to reward — it is the gap between what arrived and what was expected. In 1997, Schultz found this gap encoded in a dopamine neuron firing pattern. The math was formalized as the Rescorla-Wagner equation. Claude can simulate all three.
- The artifact: A Python script (`04-td-learning.py`) that implements the Rescorla-Wagner learning rule (delta_V = alpha * delta * lambda, where delta is prediction error) and the Temporal Difference (TD) learning extension, plots: V (expected reward) over trials, prediction error (delta) over trials, and shows how blocking works (redundant CS learns nothing). Includes presets for Pavlov's original experiment and Schultz's dopamine experiment structure.
- Prompt seed: `claude "Build 04-td-learning.py: a Python script implementing Rescorla-Wagner and TD learning. Implement: (1) Rescorla-Wagner: V_{t+1} = V_t + alpha * (lambda - V_t) for a CS-US pairing, where alpha=learning rate, lambda=US magnitude, V=associative strength; (2) plot V over 50 trials showing acquisition; (3) plot prediction error (delta = lambda - V_t) showing it start large and approach zero as learning completes; (4) demonstrate blocking: train CS1→US to asymptote, then add CS2 alongside CS1; show CS2 never acquires associative strength; (5) a TD-learning variant where the CS has temporal structure (5 timesteps before US) and show how the prediction migrates backward to the CS onset. Comment every equation."`
- Read / check: The Rescorla-Wagner equation should be correctly implemented (alpha typically 0.1-0.3; asymptote at alpha=lambda/(alpha*lambda) — i.e., V approaches lambda). Blocking should demonstrably prevent CS2 from acquiring associative strength because delta≈0 when CS1 is already predicting the US. The TD temporal structure should show the prediction error peak migrating from US time backward toward CS onset over training.
- Human supplies (Claude can't): Nothing — fully synthetic. The Rescorla-Wagner equation and TD learning are well-defined mathematical models. Real neurophysiology data (Schultz's actual dopamine recordings) would enrich the comparison but are not required for the video.
- Output medium: screen-recording mp4 (terminal running the script; matplotlib showing the three panels: V over trials, delta over trials, blocking demonstration; the TD migration animation showing the prediction error moving backward in time)
- The change: Ask Claude to extend to a Q-learning agent in a simple 2-arm bandit task — showing how TD error drives choice policy update — and visualize the exploitation-exploration trade-off as epsilon-greedy parameter varies.
- Teardown angle: The prediction error is not a metaphor for learning — it is the literal teaching signal in the brain. Schultz's dopamine neuron was computing ΔV = received - expected at every moment. The Rescorla-Wagner equation, derived in 1972 from behavioral data alone, turned out to be the algorithm the dopamine system was running. Behavioral psychology and neuroscience had converged on the same computation from opposite directions.
- Exclusions: NMDA receptor as the synaptic basis of prediction error (deep dive), serotonin and punishment, serotonin vs. dopamine debate.

Produce: (1) O'Keefe 1971 place cell discovery — Journal of Physiology, what he was studying, what he found, the Nobel Prize 2014; (2) Hafting et al. 2005 grid cells — Science paper, hexagonal lattice structure, lattice spacing (~30-300 cm), orientation, phase offset, how different grid cells tile the environment; (3) why hexagonal rather than square (most efficient tiling of a 2D plane); (4) grid cells as a path integrator — how self-motion signals (velocity, heading) update firing fields continuously; (5) landmark-grid-place cell interactions — how landmarks anchor the grid, how place cells remap in new environments; (6) the Cataglyphis ant comparison — path integration without a grid system.
