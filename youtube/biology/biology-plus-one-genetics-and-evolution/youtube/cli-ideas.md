## Candidate 02 — "Build the Hardy-Weinberg + Selection Simulator with Claude Code"

- **Lane:** BUILD (Claude Code)

Verification: (1) with no forces, p stays constant (Hardy-Weinberg equilibrium); (2) with s=0.5 against aa, q decreases monotonically; (3) with N=10, drift produces visible random walk; (4) population p² + 2pq + q² sums to 1.0 at every generation.
- **Prompt seed:** `claude "Build a population genetics simulator in a single self-contained HTML file using D3 v7 from CDN. Parameters: initial p (0–1 slider), selection coefficient s_aa (0–1, acts against aa genotype), population size N (10–10,000, log slider), migration rate m (0–0.1), mutation rate μ (0–0.001). Simulate 100 generations using Wright-Fisher sampling when N is finite (sample 2N alleles each generation with frequency p after selection). D3 line chart shows p(t) over generations. Readout shows: current p, q, genotype frequencies (p², 2pq, q²), sum check. Console on load: (1) p=0.5, s=0, N=10000, m=0, μ=0 → p after 100 generations within 0.05 of 0.5; (2) p=0.5, s=0.5 against aa → q decreases monotonically over 100 generations; (3) p=0.5, N=10, s=0 → high variance in trajectory across 3 runs; (4) p²+2pq+q² = 1.0 at every generation."`
- **Read / check:** Run all four console biology checks. At N=10, rerun three times — confirm visible divergence between runs (drift). At N=10,000, three runs should nearly overlap (negligible drift). With s=0.5 against aa and p=0.5, verify q drops but never reaches 0 in 100 generations (selection is slow on recessives at low q — Hardy-Weinberg protects the recessive in heterozygotes).
- **Human supplies (Claude can't):** Nothing — fully synthetic. The Wright-Fisher sampling loop is the key computational piece — verify the code actually samples from a binomial(2N, p_after_selection) each generation rather than updating p deterministically.

The contrast between drift-dominated and selection-dominated regimes is the moment.
- **The change:** Add a mutation-selection balance calculation. Set μ=0.00001, s=0.5 against aa. Run to equilibrium. The equilibrium q* should be approximately √(μ/s) = √(0.00002) ≈ 0.0045. Display the theoretical prediction alongside the simulation result. Ask Claude to add a text readout showing the theoretical q* and whether the simulation matches.
- **Teardown angle:** Dominance is a statement about expression in the heterozygote. Frequency is a statement about how many copies exist in the population. They are independent facts. Hardy proved this in an afternoon because the math is elementary. The reason it wasn't obvious to the critics is that the two concepts were confused. The simulation makes the independence visible.
- **Exclusions:** Don't implement sexual selection, non-random mating, or the full coalescent model; skip linkage disequilibrium; no multi-locus simulation (that's a separate chapter).
