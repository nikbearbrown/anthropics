# Carry One Tool That Finds the Rest

**What this is.** A show-tell explainer (about 2.4 minutes) of tool search in the Claude API, drawn as one cast. Loading every tool definition fills Claude's context before any work starts; Anthropic's cookbook says that past about a hundred tools this becomes impractical. Instead Claude carries one tool, tool search, and every other definition is still sent but marked `defer_loading`, so it stays out of the context until a search finds it. The cookbook's version searches by meaning: each definition becomes text, a small embedding model turns it into 384 numbers, and the query "I need to check the weather" lands closest to get_weather, get_forecast and get_air_quality. The search sends back only their names; the API expands them into full definitions. The live docs also offer a built-in tool search on Anthropic's side (a pattern version and a plain-query version), and suggest it from ten tools up, with your three to five most used tools kept loaded. "~100 tools" is attributed to the cookbook; the notebook's "90%+" was left out because its stated basis (19+ tool definitions) contradicts its own 8-tool library.
