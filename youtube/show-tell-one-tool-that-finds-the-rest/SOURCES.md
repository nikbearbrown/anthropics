**What this is.** The primary sources for every claim, and how each one was read. **Why.** The card names a cookbook notebook, and the batch brief says the live docs win where a local copy has drifted, so the film checks the notebook against the raw live docs page. Naming Anthropic's docs and repo is fine (the bookloop law does not apply to this batch). **Found.** The live docs offer a built-in, server-side tool search; the notebook builds the custom, client-side version with embeddings, which the docs also support. The notebook's request code never sets `defer_loading`, so the film follows the live docs for how deferral works.
