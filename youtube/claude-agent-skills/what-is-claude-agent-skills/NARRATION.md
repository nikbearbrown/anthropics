## B00 (Cold Open)
Namaste, Bear. Computational skepticism is the lens here, and Descartes donates the move — what would have to be true for this to go wrong? Ask it about your own skill and you get a checklist instead of a feeling. Here's when a folder of instructions beats a better prompt.

## B01 (Wrong model)
The wrong model: pasting the same four-hundred-word instruction block at the start of every session and calling it a workflow. It works. It's also manual, fragile, and invisible to anyone else.

## B02 (Right model)
The right model: a SKILL.md that Claude reads before starting. Instructions plus the assets they need, loaded when relevant. Write it once; it invokes automatically.

## B03 (Playlist contents)
The playlist covers four things: what goes in a SKILL.md, writing the description so it triggers correctly, including assets and scripts, and knowing when a skill is overkill.

## B04 (Do now)
Find the instruction block you've pasted three or more times this month. That's your first skill.

## B05 (Verdict)
Who this is for: people who catch themselves repeating instructions session to session. Not for one-off tasks — a skill for something you do once is worse than a prompt. Falsifiable line: if a SKILL.md produces lower-quality output than the instruction block it replaced, the overhead isn't worth it.
