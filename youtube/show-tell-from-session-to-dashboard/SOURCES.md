# SOURCES — show-tell-from-session-to-dashboard

**What this is.** The primary sources for every claim in the film, and how they were read. **Why.** The Batch 2 brief requires fact-checking against RAW sources, and where a local copy may be stale, following the live docs. **Found.** The eight local guide files are byte-identical to the raw upstream files, but the guide itself is older than the live Claude Code docs in three places (seven metrics vs eight; its `managed-settings.json` shape; its clone line names an older repo). The film follows the live docs there and uses no prices, ROI dollar figures or sample numbers.

1. **The guide, `anthropics/claude-code-monitoring-guide/`**, read in full 2026-09-27: `README.md`, `claude_code_roi_full.md` (Quick Verification with the console exporter; Prometheus Setup env vars; Key Prometheus Queries; Core and Additional metrics tables; Automated Reporting with `claude -p` and the Linear MCP, `fetch-claude-metrics.sh`; Organization Deployment), `docker-compose.yml` (otel-collector 4317/4318/8889, prometheus 9090 with 200h retention, grafana 3000), `otel-collector-config.yaml` (OTLP receiver on 4317 gRPC / 4318 HTTP; `batch` timeout 1s; `prometheus` exporter on 8889 plus `debug`; ONE pipeline, `metrics`), `prometheus.yml` (`scrape_interval: 15s`; scrapes `otel-collector:8889`), `report-generation-prompt.md`, `troubleshooting.md`, `grafana/dashboards/working-dashboard.json` (eight panels: Total Cost, Active Users, Total Tokens, Lines of Code, Cost by Model, Token Usage by Type, Cost by User, Lines of Code by Type) and `grafana/provisioning/dashboards/dashboards.yaml`. Note: the repo provisions the dashboard but ships no Grafana data-source file.
2. **Raw upstream copies**, fetched with curl on 2026-09-27 from `https://raw.githubusercontent.com/anthropics/claude-code-monitoring-guide/main/<file>` (HTTP 200) for the seven top-level files, saved as `sources/live_<file>`; `cmp` against the local copies: identical.
3. **Live Claude Code monitoring docs**, fetched raw with curl on 2026-09-27 from `https://code.claude.com/docs/en/monitoring-usage.md` (HTTP 200, 177,479 bytes), saved as `sources/live_monitoring-usage-2026-09-27.md`. Used: Quick start (env vars; verify with `claude_code.session.count`); Administrator configuration (managed settings `env` block; repository settings can't turn telemetry on or choose where it goes; `OTEL_*` not passed to subprocesses); Common configuration variables (`OTEL_METRIC_EXPORT_INTERVAL` default 60000); Standard attributes (`session.id` default true); Metrics (eight); Token and Cost counters (`type`, `model`); Events (via `OTEL_LOGS_EXPORTER`); Cost monitoring ("Cost metrics are approximations"); Security and privacy (opt-in; no raw file contents or code snippets in metrics/events; prompt content not collected by default, only length; `user.email` only to your endpoint, never to Anthropic); ROI measurement resources (links the guide repo). No WebFetch summary was used anywhere.

**Not used, on purpose:** every price, plan cost and ROI dollar figure (card #28 caution); the guide's sample query results, "real-world telemetry snapshot" and sample report numbers; the Anthropic research percentages quoted in the guide (secondary, not about the pipeline); traces (beta) and the many event types beyond one mention; the guide's Haiku prompt-analysis pseudo-code; the author credit (the film credits the repo, as the docs do).

4. **Cast and patterns reused** from the batch's earlier show-tell films: the ISO KIT; the midpoint guard (`ST`/`guard`) from `show-tell-context-is-a-budget/`; the extra-dark faces from `show-tell-one-tool-that-finds-the-rest/`; `build_srt.py` copied from `show-tell-two-mirror-prompts/`.
