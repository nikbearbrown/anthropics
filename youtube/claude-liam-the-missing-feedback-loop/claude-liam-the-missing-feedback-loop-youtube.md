The Missing Feedback Loop

AI took off in software for a mechanical reason: code has a cheap, instant, unambiguous verifier. Write, run, read the failure, revise. The physical world never had that loop — which is the real reason AI stayed on the screen.

Anthropic's Model Hardware Standard is a bet that the loop can be built for physical equipment. This film gives the mechanism its due — the driver-and-manifest architecture is real, the integration-cost collapse is real, and the QuEra laser result is genuinely strong — then does the work the headlines skip:

• Claude wrote the operator. It is not the operator. What ships is a deterministic decision tree — inspectable Python with no model in the loop.
• The verifier is the custom part. A compiler checks essentially all code for free; every physical task needs its own sensor, and nobody standardizes that.
• Programmatic is not physical. When bubbles formed in a viscous sample, the model's instinct — retry the same well — made the foam worse.
• Every number here is company-reported. One vendor announcement, cooperative partners, no peer review, no independent replication, nothing open-sourced yet.

The numbers, precisely: the prior baseline was a linear recovery script built by a four-person team over several months — 58% success at ~150 seconds per attempt. The agent-developed controller recovered the lock in 695 of 700 blind trials (99.3%), in 0.9–5.4 s for simple faults and 10–14 s for the hardest, against 5–10 minutes for a human at the bench. A second, quieter result: servo tuning that cut residual error from 15.7 mV to 1.55 mV and held lock for 19 hours without a single loss.
