# Context Is a Budget

**What this is.** A 158-second show-tell explainer of Anthropic's "Effective context engineering for AI agents", drawn as one isometric tray (the context window) filling with blocks. It has labels only, and Liam's voice does the explaining. **Why.** Card #3 in `../show-tell-ideas.md`; Bear said to build all eight cards in order (2026-09-26). It reuses the tray that stood for "context" in show-tell-how-a-skill-loads. **Found.** Every claim matches the article. Context is finite, with diminishing returns ("context rot"; the "attention budget", n² pairs). The goal is the smallest set of high-signal tokens: curate what goes in, load data just in time from lightweight references, and on long tasks use compaction, structured note-taking, and sub-agents. The only numbers spoken are the article's own ("tens of thousands of tokens", "often one to two thousand tokens"). Claude Code's compaction details are attributed to Claude Code.

- The beats: the tray (B00); an agent in a loop piles blocks in, and everything pales (context rot, B01); why, the n² web of token pairs (B02); curate: pale blocks out, a clear prompt, two tools instead of three, three examples instead of a laundry list (B03); just in time: data stays in a crate outside the tray, only a file-path tag and the slices you need come in, head and tail (B04); compaction: a press squeezes the kept blocks into one summary, and the tool outputs are dropped (B05); note-taking: a NOTES.md notebook outside the tray, read back after a reset (B06); sub-agents: three small crates fill up and each sends one summary card back (B07); the rule (B08); your turn.
- The cast: a kraft tray; white instruction page, dark tool blocks, kraft message blocks, white result slabs, a taped data box; a needle card; a data crate; a dark press; a notebook; small sub-agent crates.
