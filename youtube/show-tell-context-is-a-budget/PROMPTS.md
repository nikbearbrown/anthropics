**Your Turn (BHTF)**, shown and read in full:

```
Here's a long task I run with an AI agent: [describe it in two sentences]. List everything that lands in its context. Mark each item: keep, load only when needed, compact, move to a notes file, or hand to a sub-agent. Then write the summary you'd keep if the context reset right now.
```

The viewer's two checks: for each item they kept, does the next step actually use it (if not, cut it); and paste only the summary into a fresh chat — can Claude say what's done and what's next?
