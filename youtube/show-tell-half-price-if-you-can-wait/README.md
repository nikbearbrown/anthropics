# Half Price If You Can Wait

**What this is.** A show-tell explainer (about 2.5 minutes) of the Message Batches API in the Claude API, drawn as one cast. The usual way is a loop: one request, one wait, one answer, at the standard price. A batch is the same requests in one list, each an ordinary Messages request with a `custom_id` tag you choose. You submit the list in one call and get a batch ID back at once, status `in_progress`. The requests run asynchronously, each on its own, so they finish in any order and one failure holds up nothing; the docs say most batches finish within an hour and a batch not done in 24 hours expires. Your code polls until the status is `ended`. Results come back in any order, so you match them by `custom_id`, never by position. Each result says `succeeded` or `errored`; errored ones aren't billed, so you resend only those. Anthropic's docs say all batch usage is charged at 50% of standard API prices, and results stay available for 29 days.
