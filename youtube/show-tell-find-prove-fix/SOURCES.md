# SOURCES — show-tell-find-prove-fix

**What this is.** The primary sources for every claim, and how each one was read. **Why.** The film fact-checks against Anthropic's own security write-up and its reference harness, both saved in this tree. Naming the post and the repo is fine (the bookloop law does not apply to this batch).

1. **`anthropics/defending-code-reference-harness/docs/blog-post.md`** ("Using LLMs to secure source code", by Eugene Yan and Henna Dattani with contributors; read in full 2026-09-27) — the takeaway ("discovery is now straightforward to parallelize, and the bottleneck has shifted to verification, triage, and patching"); the count ("as of May 22, 2026, we had disclosed 1,596 vulnerabilities. To our knowledge, 97 of these have been patched"); the six steps and "two ... setup ... four ... loop"; §1 threat model (trust boundaries as "the most common cause of false positives", "Name what *is* trusted"); §2 sandbox (network only during setup, snapshot, "allow traffic only to the model API", no credentials); §3 discovery (partition, parallel agents, "increasingly simple prompts"); §4 verification (independence, the partner-team "near zero", "failure to produce a working PoC is not proof of a false positive"); §5 triage (root cause, reachability, blast radius); §6 patching (failing test first, the four-check ladder, "a human still needs to own it"). **Not used:** single-team anecdotes and their figures (90%, 40%, "nearly 100 percent"), and product names beyond the repo.
2. **`docs/pipeline.md`** (read in full) — Build, Recon, Find ("until an input crashes 3 out of 3 times. It outputs the crashing input file"), Grade ("a fresh container ... The only thing that crosses ... is the PoC bytes"), Judge, Report, Patch; C/C++ memory vulnerabilities; the gVisor sandbox warning.
3. **`README.md`** (read in full) — "a **reference, not a product**", "This repo is not maintained and is not accepting contributions", the seven stages, the Day-1 read-only skills, and "Autonomous triage and patching are still open issues, and this reference harness doesn't fully solve them".
4. **`docs/patching.md`** (read in full up to the CLI reference) — the verification ladder (Build, Reproduce, Regress, Re-attack; Style advisory only) and its limit ("proves the specific crash is fixed, but does **not** prove the root cause is addressed").
