# Agent Decomposition: Skills vs Tools — Show-Tell remake

A readability-first rebuild of the existing workshop video, requested by Bear on September 30, 2026. The source video is preserved in `../../cwc-workshops/youtube/agent-decomposition-skills-vs-tools/`.

The new version uses one animated isometric illustration per body beat, a recurring cast of pages, tool blocks, and context trays, and 56–64pt Manim labels. Liam narrates the explanation; the pictures show instruction loading, tool calls, delegation, approval, batching, and measurement. No dense architecture slides or code listings.

The script also corrects the distinction between a skill and a subagent, and attributes the reported performance figures to the StockPilot workshop rather than promising those results to every viewer.
