# SOURCES — show-tell-loop-that-wont-let-go

**What this is.** The primary source for every claim, and how it was read. **Why.** The film explains one mechanism, the Ralph Loop plugin's Stop hook, and two copies of that plugin sit in this tree with different files. **Choice.** The film uses ONE copy: `anthropics/claude-plugins-official/plugins/ralph-loop/`. It is the copy listed in the official directory's `.claude-plugin/marketplace.json` (entry `ralph-loop`, author Anthropic, source `./plugins/ralph-loop`), and that directory's README says `/plugins` holds "Internal plugins developed and maintained by Anthropic". Its hook is also the newer code (see "The other copy"). Naming the plugin and repo is fine (the bookloop law does not apply to this batch).

## The source (read in full, 2026-09-27)
1. **`plugins/ralph-loop/README.md`**: "Ralph is a Bash loop" (Geoffrey Huntley's phrase, quoted by the README); the plugin "implements Ralph using a **Stop hook** that intercepts Claude's exit attempts"; the five-step flow (works, tries to exit, Stop hook blocks exit, feeds the SAME prompt back, repeat); "The prompt never changes between iterations", "Claude's previous work persists in files", "Each iteration sees modified files and git history"; command usage `/ralph-loop "<prompt>" --max-iterations <n> --completion-promise "<text>"` ("default: unlimited"); `/cancel-ralph`; "Clear Completion Criteria"; "Escape Hatches: Always use `--max-iterations` as a safety net to prevent infinite loops on impossible tasks"; "The `--completion-promise` uses exact string matching, so you cannot use it for multiple completion conditions (like "SUCCESS" vs "BLOCKED"). Always rely on `--max-iterations` as your primary safety mechanism."; "Good for ... Tasks with automatic verification (tests, linters)"; "Not good for: Tasks requiring human judgment or design decisions ... Tasks with unclear success criteria". **Not used:** the "Real-World Results" list ($50k contract for $297 in API costs; 6 repositories overnight; a programming language over 3 months), which the README states without a source; the Windows notes.
2. **`plugins/ralph-loop/commands/ralph-loop.md`**: runs `scripts/setup-ralph-loop.sh $ARGUMENTS`; "When you try to exit, the Ralph loop will feed the SAME PROMPT back to you"; "CRITICAL RULE: If a completion promise is set, you may ONLY output it when the statement is completely and unequivocally TRUE. Do not output false promises to escape the loop".
3. **`plugins/ralph-loop/scripts/setup-ralph-loop.sh`**: writes `.claude/ralph-loop.local.md` with YAML frontmatter (`active`, `iteration: 1`, `session_id`, `max_iterations`, `completion_promise`, `started_at`) and the prompt below it; "--max-iterations <n> Maximum iterations before auto-stop (default: unlimited)"; "STOPPING: Only by reaching --max-iterations or detecting --completion-promise. No manual stop - Ralph runs infinitely by default!"; "WARNING: This loop cannot be stopped manually! It will run infinitely unless you set --max-iterations or --completion-promise."; "To complete this loop, output this EXACT text: <promise>$COMPLETION_PROMISE</promise>".
4. **`plugins/ralph-loop/hooks/hooks.json`**: registers `hooks/stop-hook.sh` under the `Stop` event.
5. **`plugins/ralph-loop/hooks/stop-hook.sh`**: no state file → allow exit; another session's loop → allow exit; `iteration >= max_iterations` (when max > 0) → delete the state file, allow exit; reads the last assistant text block from the transcript; if the text inside the first `<promise>…</promise>` equals the completion promise (literal `=` comparison, whitespace normalised) → delete the state file, allow exit; otherwise increments `iteration` and prints `{"decision": "block", "reason": <the prompt>, "systemMessage": "🔄 Ralph iteration N | …"}`.
6. **`plugins/ralph-loop/commands/cancel-ralph.md`**: checks for `.claude/ralph-loop.local.md`, reads the iteration, removes the file, reports "Cancelled Ralph loop (was at iteration N)".
7. **`plugins/ralph-loop/commands/help.md`**: the same flow in plain words; "Without it (or `--max-iterations`), Ralph runs infinitely."
8. **`plugins/ralph-loop/.claude-plugin/plugin.json`** and **`claude-plugins-official/README.md`** (install line `/plugin install {plugin-name}@claude-plugins-official`; "Make sure you trust a plugin before installing").
9. For the one-line definition of a Stop hook only: `anthropics/claude-code/plugins/plugin-dev/skills/hook-development/SKILL.md`, "### Stop: Execute when main agent considers stopping." (consistent with the README's "intercepts Claude's exit attempts").

## The other copy (diffed, NOT used as a source)
`anthropics/claude-code/plugins/ralph-wiggum/` (name `ralph-wiggum`). Differences found by `diff`: its README and help are titled "Ralph Wiggum" and have no Windows section; its setup script writes no `session_id`; its stop hook has no session isolation, reads only the single last assistant line, and stops the loop when that message has no text (the official copy continues instead). Command names, flags, the state-file path and the block-and-feed-back mechanism are the same in both, so nothing the film says depends on which copy a viewer has, but every citation is to the official copy.
