# Claude Asks, Your Code Runs

**What this is.** A 131-second show-tell explainer of tool use (function calling) on the Claude API, drawn as one cast: Claude is a dark block on a kraft desk, your code is a dark machine at the far end of a belt, a tool is a card (name, description, input schema), and requests and results are slips whose terracotta dot is the id. Labels only; Liam's voice does the explaining. **Why.** Card #10 in `../show-tell-ideas.md` (Batch 2, the foundation under every agent film), built on Bear's overnight order of 2026-09-27. **Found.** Every claim matches Anthropic's tool-use course (`anthropics/courses/tool_use/01` and `04`) or, where the course is out of date, Anthropic's current docs. You send a question plus tool definitions; Claude answers with a `tool_use` block and stops (`stop_reason: tool_use`); your code extracts the name and input, runs the real function, and returns a `tool_result` in a new user message carrying the request's id; Claude then writes the answer. Claude may ask for several tools in one response, and all results go back together, each matched by id. It can skip the tool when it already knows the answer (a system-prompt line steers this; the notebook's own run shows it over-calling without one). The course's line that Claude has no server-side tools is out of date: Anthropic now runs a few itself (web search, code execution), while every tool you define, your code runs.
