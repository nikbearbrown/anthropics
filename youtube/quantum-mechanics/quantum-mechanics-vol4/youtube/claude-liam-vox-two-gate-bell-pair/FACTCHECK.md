# Factcheck

VERDICT: PASS

- Starting from `|00>`, Hadamard on the control gives `|+> tensor |0>`, which is superposed but separable.
- CNOT maps the two branches to `|00>` and `|11>`, producing the maximally entangled pure state `|Phi+>`.
- Computational-basis outcomes `00` and `11` each have probability one half.
- Each single-qubit reduced state is maximally mixed and has zero Bloch vector; this is explicitly not described as physical collapse.
- Reversing the gate order on `|00>` does not produce the same Bell state.
- Four-by-four matrices, the full Bell table, and universality discussion are excluded.
