# Five Reviewers and a Sieve

**What this is.** A show-tell explainer (4:11) of how the code-review plugin in Anthropic's official Claude Code plugin directory works, drawn as a pull request on a table with five reviewers around it and a sieve set at 80. The command, `/code-review`, runs on a pull request: a Haiku agent checks it is worth reviewing (not closed, draft, trivial or already reviewed); a Haiku agent lists the CLAUDE.md paths; a Haiku agent summarises the change; then five Sonnet reviewers work in parallel (CLAUDE.md rules, obvious bugs in the changed lines, git blame and history, comments on earlier pull requests, code comments). Every issue gets its own Haiku scorer on a verbatim 0–100 rubric, the command filters out "any issues with a score less than 80" (so a 75, "highly confident", still falls through), repeats the eligibility check, and posts one brief comment with `gh`, each issue linked with the full commit hash. Labels only; Liam's voice does the explaining. **Why.** Card #31 in `../show-tell-ideas.md` (Batch 2), built on Bear's overnight order of 2026-09-27. **Found.** The plugin's README says four reviewers, but the command file that Claude executes launches five. No scores are averaged.
