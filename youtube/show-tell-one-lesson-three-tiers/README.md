# One Lesson, Three Tiers

**What this is.** A show-tell explainer (about 4 minutes) of Anthropic's `k12-lesson-differentiation` skill, following the LIVE upstream files of `anthropics/k12-teacher-skills`. The skill starts from a lesson the teacher already teaches, which the teacher shares or names; it never writes new lessons, which another skill does. It splits that lesson into three tiers (below, at and above grade level) that share one core: the same standard, context and core tasks, with only the supports changing. In one turn it returns four editable Word documents: a plan for the teacher and one worksheet per tier. Before that, it routes silently by subject and reads that subject's mandatory rulebook, grounds the lesson in its standard (it must look the standard up before drafting when the Learning Commons Knowledge Graph connector is on, and says so in a footer when it isn't), checks the state (Common Core / NGSS by default, and asks first for social studies), folds in stated learner needs (UDL defaults otherwise), and offers a quick draft first (the full set is the default). The below tier is taught up, not made easier: in the skill's own pizza-fractions example, it gets a pizza to shade and then the same question. Scaffolds never give the answer and fade two, one, none. The above tier's extension must ask for new thinking. Student pages say only Group A, B and C. Shared content is written once, so an edit to it updates all four documents, while a one-tier change stays in that tier. The plan states what each group is based on and that groups can change after this lesson's check. The skill ends when the teacher says they're satisfied. **Why.** Card #30 in `../show-tell-ideas.md` (Batch 2), built on Bear's overnight order of 2026-09-27. **Found.** The local repo copy is older than upstream (the live SKILL.md moved its output rules into `references/output.md` and renamed the sibling skill `k12-lesson-plan-creation`); the film follows the live files and states no number they don't.
