# The Inspector Says No First

**What this is.** A 158-second show-tell explainer of the quality loop for long-running Claude agents, drawn as a workshop: a builder at a bench, every part stamped FAIL until it earns PASS, an inspector in a closed booth, a handoff clipboard, the loop, the operator's stop file, and `/goal`. It has labels only, and Liam's voice does the explaining. **Why.** Card #5 in `../show-tell-ideas.md`; Bear said to build all eight cards in order (2026-09-26). **Found.** Every claim matches `anthropics/cwc-long-running-agents` (README, `evaluator.md`, `CLAUDE.md`, `settings.json`, the five hooks). Left alone, a builder marks a feature passing after a unit test even when the screen is broken, and asking nicely doesn't reliably stop it. The fix is structural: every row in `test-results.json` starts false; a hook refuses the write until the builder has opened evidence, and each read unlocks one write; a separate evaluator with a fresh context and no Write or Edit tools reads the spec, the diff and the screenshots, says PASS or NEEDS_WORK, and its findings start the next session; the builder keeps `PROGRESS.md` and commits so the next session picks up cleanly; the loop ends when no row is false, a cycle changes nothing, or the budget runs out; `AGENT_STOP` halts every tool call and `STEER.md` redirects mid-run. `/goal` is the built-in checker (a separate fast model checks your condition after every turn). Two overclaims in the idea card were corrected (see FACTCHECK): the shipped loop exits on the contract file, not on the inspector's PASS, unless you wire it that way; and `/goal` is described only as the README describes it.

- The beats: a builder that grades itself (B00); flip the default, every row false (B01); the hook, no write without evidence (B02); the inspector's booth, a fresh context (B03); PASS or NEEDS_WORK, findings ride back (B04); the handoff note and the commits (B05); the loop and its exit (B06); AGENT_STOP and STEER.md (B07); `/goal` versus your own `evaluator.md` (B08); your turn: have Claude Code write a default-FAIL evaluator for one long task of yours, then test it with a commit that has no screenshot.
- The cast: a kraft workbench with the dark builder station, a part crate with a white FAIL/PASS tag, the results board, the hook arch over a belt with a drop bar, a screenshot card showing the crack, a closed kraft booth behind a wall, a clipboard and a grey commit stack, the loop belt, a stop file and a steer note, a small dark `/goal` booth.
