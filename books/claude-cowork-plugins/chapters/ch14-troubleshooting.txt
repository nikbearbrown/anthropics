Chapter 12. Troubleshooting and staying current. Things will go wrong. Plugins won't behave as expected. Connections will fail. Results will disappoint. Knowing how to diagnose and fix problems keeps frustration from becoming abandonment. Common issues. Plugin doesn't appear after installation. Close co-work completely and reopen it. Plugins load its startup so changes sometimes require a full restart. If it still doesn't appear, try reinstalling from the plugin's sidebar. Connected service won't authenticate. Check that your credentials are current. API tokens expire. Passwords change. Trades get revoked. Try disconnecting and reconnecting the service. If your company has IT restrictions on third party access, you may need approval. Plugin works but results are generic. This usually means customization is needed. Out of the box defaults are intentionally broad. Customize the plugin with your specific context. Brand voice, sales process, document standards, and results improved dramatically. Pressure slow. Plugin operations that reach external services. CRM queries. Database lookups. Web research. Take longer than local operations. Reduce scope when possible. Query a specific date range instead of everything. Or focus on a specific folder instead of searching all connected repositories. Slash commands aren't recognized. Make sure the plugin is installed and enabled. Type. To see all available commands. If the command still doesn't appear, the plugin may need a restart. Quick diagnostics. Type slash plugins in co-work to see which plugins are installed and active. This is your first check for any plugin related issue. If a specific plugin is misbehaving, try disabling and re-enabling it. This reloads the plugin's configuration and often resolves transient issues. Staying current. Plugins evolve. Andthropic improves the official plugins regularly. And community plugins receive updates from their creators. Staying current matters because updates bring new capabilities, fix bugs, and improve performance. Check for updates periodically. Global work handles most updates automatically, but it's worth checking the plugin directory and GitHub repositories for announcements about significant changes. Watch for new plugins. The ecosystem is growing. New official plugins, community contributions, and third party integrations appear regularly. Set a monthly reminder to browse the directory and see what's new. Follow the change log. When a plugin you use gets a significant update, review what changed. New features might be exactly what you needed. Change behavior might require adjusting your workflows. Andthropic's official channels. The Anthropic blog and the cloud release notes are the most reliable sources for co-work and plugin updates. Check them when you hear about new developments. Where to get help. Plugin documentation. Each official plugin has documentation on its GitHub page and in the co-work interface. Start here for specific questions about capabilities and configuration. The plugin directory. Community discussions and user reviews at cloud.com slash plugins can surface solutions to problems others have already solved. Anthropic support. For account, billing, or access issues, Anthropic support channels are the right path. The approach that works. When something doesn't work, check that the plugin is installed and active.
