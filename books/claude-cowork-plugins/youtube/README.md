# Deep-Explainer Series — *Claude Cowork Plugins*

One Liam-persona, Claude-branded deep-explainer per chapter (skill: `deep-explainer`, channel `claude-liam`, Kokoro `am_onyx`, free). Fourteen episodes, built in chapter order.

**Status: authoring complete, render pending.** Every reel folder holds the full authoring package (`beat_sheet.json` + `PLAN.md` + `SOURCES.md` + `BUILD-PROMPT.md`) and the empty slot dirs (`pantry/ media/ manim/ clips/ mp3/`). Rendering — schema-reconcile, GATE P, Kokoro audio, Manim/Remotion, pantry stills, previz, QC, final — runs on the `brutalist-art` toolkit machine, which is not in this authoring sandbox. Start each reel with its `BUILD-PROMPT.md`, or the whole batch with `BUILD-ALL.md`.

**All claims were checked first** against `../FACTCHECK.md`. Datable specifics (plugin counts, prices, platform lists, vendor names) are stripped from every reel per DOUBLE-CHECK LAW — the episodes carry the durable concepts, not the facts that will date.
