# Vibecoders Welcome: I Don't Code. I Built a Tool With Claude Code Anyway.

Vibecoding means you describe a tool in plain words, Claude Code writes it, and you decide whether it's right — not by trusting it, by reading it.

This film builds a reading log I'd actually use, from one paragraph. Claude Code writes it in one pass. Then the checks: it added two features nobody asked for, announced one of them, and after the correction it wrote a note about me outside my folder. Every check is a command, every output is real, and the session transcript ships with the film.

## Your turn

Make an empty folder, open Claude Code in it, and describe one small tool you'd actually use, in a paragraph that lists every constraint you care about. Before you run what it writes, paste this: "List everything you built that I did not explicitly ask for, and everything you wrote outside this folder. Then tell me which of those you would remove if I asked for exactly what I asked for and nothing else."
