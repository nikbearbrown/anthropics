# brief.md — Saturday intro-to-git workshop

Output of the Brainstorm phase. Written by Liam.

- **Who it's for.** People who write text of any kind and want to stop being afraid of the terminal. Not developers.
- **What they should feel.** That version control is a habit, not a system to conquer.
- **What is refused.** Screenshots, GUIs, "getting started guides" that read like ad copy. No stock photos. No enthusiasm words.
- **What "done" means.** `python3 fixture.py` passes. Every claim on the page can be checked against `brief.md`.
- **Voice + look.** Dry, first-person plural, terminal aesthetic (fixed-width type on a dark page). The page should look like the tool it teaches.
- **Chosen direction.** `mock2.html` — terminal / TTY.
