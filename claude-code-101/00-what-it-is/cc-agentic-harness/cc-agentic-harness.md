# Claude Code Is an Agentic Harness. What Is That?

Claude Code is not a better model. It's the same model you talk to in the chat window, wrapped in a harness: a list of what it may touch, rules about touching it, and a loop that keeps asking "what next."

This film shows the harness by switching it off. The same one-line ask, three ways: with no tools at all, the model says "Creating the file now" and creates nothing. With the built-in tools off but the connectors still attached, it reaches for Google Drive and the permission layer says no. With Write on the list, one call, one file. Then a ten-line shell loop runs Claude Code three times with a fresh session each pass and a task file as the only memory — three for three. Every run is real; the transcripts are in the film.
