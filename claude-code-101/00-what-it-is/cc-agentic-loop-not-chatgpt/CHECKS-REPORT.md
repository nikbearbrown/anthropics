- The **misconception** (BIDEA correction word): `chatbot` → `loop`. The single word the film exists to fix.
- The **prediction-before-reveal**: BDEFS names *calibration* and *the five questions* before any run shows them.
- The **first cycle failure**: cycle 1 (B01–B03) ends on receipts — an email input and a `mailto:REPLACE-WITH-…` placeholder — that visibly contradict the site's footer discipline. The wrong assumption is not narrated; it is on screen.
- The **correction**: cycle 2 (B04–B06) runs on the same folder, same three Reads, and produces zero edits. The comparison is a receipt-vs-receipt argument, not an authority claim.
- The **falsifiable line** (BVDT closing bullet): "a chatbot-style ask that returns without writing to disk, on a repo it has never seen." This is the falsifiability beat.
- The **scaffolded practice** (BHTF): the viewer runs a calibration session on a project *they* care about. The prompt is a straight paste of the five questions.
