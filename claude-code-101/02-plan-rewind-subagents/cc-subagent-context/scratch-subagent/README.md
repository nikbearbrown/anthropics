# studygroup grader

Tiny grader used by the study group. Reads a submission JSON, prints a grade.

- `grader.py` — the tool
- `test_grader.py` — the tests (unittest, `python3 -m unittest test_grader`)
- `policies/` — the group's written policies. Read only when a policy question comes up.

The build task for this session lives in `ask.txt`.
