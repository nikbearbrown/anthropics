# Honor code

The Thursday study group is not a class. There is no instructor of record.
The honor code is what the group agreed to on the first evening, and it
governs every meeting after.

## The four lines

- **Read the source, not the summary.** No one presents a topic they have
  not read in the original. Textbook chapters, papers, or primary sources
  only. Wikipedia is fine as a jumping-off point; the citation trail is
  where the reading happens.
- **Say "I don't know" without apology.** The group protects the space to
  admit gaps out loud. A confident wrong answer is much more expensive
  than a slow "I don't know yet".
- **Solutions belong to whoever asks first.** If you finish a problem and
  another member is still working on it, do not volunteer the answer
  until they ask. Hints are welcome; complete solutions on request only.
- **Cite anyone whose framing you borrow.** Attribution is cheap and
  makes the group's memory legible over time.

## Enforcement

There is no penalty column. The honor code is enforced by attention. The
week's convenor mentions any breach at the start of the following
meeting, without names when possible, with names when clarity requires
it. Repeated breaches trigger a group conversation, not an ejection.
