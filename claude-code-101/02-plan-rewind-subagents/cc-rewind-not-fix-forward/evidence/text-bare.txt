Created both files. The implementations are non-mutating (new list + new dicts), which also satisfies the `check_immutable.py` script sitting in this scratch folder.

- `todos.py`
  - `remove_completed(todos)` — list comprehension filtering out `done`
  - `mark_all_done(todos)` — returns new dicts with `done: True`, preserving other fields
- `test_todos.py` — `unittest` cases for both functions covering: normal case, empty list, all-done / none-done, other-field preservation, and input-immutability.

Run with `python -m unittest test_todos.py -v` (and optionally `python check_immutable.py`) when you're ready — I didn't have permission to execute them.
