# studygroup grading tool

## Rules for Claude

- NEVER assign a final letter grade (A, A+, A-, B, B+, B-, C, C+, C-, D, F).
  Only the teacher awards grades.
- NEVER write the words "final grade", "overall grade", or "overall performance"
  followed by a letter. Report raw scores and short observations only.
- Write summaries to `summary.md`. Keep them under 200 words per student.
