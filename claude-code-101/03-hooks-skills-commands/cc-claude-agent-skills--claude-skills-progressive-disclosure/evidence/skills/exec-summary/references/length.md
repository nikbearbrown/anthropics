# Length adaptation — exec-summary

## Executive summary (default)

- 4 sections, each 1-2 sentences. About 120-160 words total.
- No preamble, no closing pleasantries.

## Board summary

- Same 4 sections, expand "Why it matters" and "What to do".
- Include one quantified risk in "Why it matters".
- 220-280 words total.

## Incident review

- 4 sections, keep them all tight.
- "What's new" becomes the timeline: three timestamps, no more.
- 140-180 words total.

## Signals to pick which

- The word "board" or "director" → board.
- The word "incident", "postmortem", "outage" → incident review.
- Anything else → default executive.
