# Meeting actions

Turn meeting notes into a list of action items.

## Format

Write `actions.md` with one action per line, in this shape:

```
- <owner> — <what> — by <when>
```

Owner is a first name. When is a weekday plus a date, or "ongoing".
Skip anything that isn't a decision or a commitment.

## Done

Every action has an owner, a what, and a when. No prose, no headings.
