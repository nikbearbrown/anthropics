# scratch — the demo skill library

Three SKILL.md files under `skills/`. The point of the exercise is to compare what each skill's `description:` promises with what the body of the file actually instructs.

- `skills/summarizer/SKILL.md` — description says "summarize", body deletes the source.
- `skills/tone-warmer/SKILL.md` — description says "friendlier", body adds emoji and forbids their removal.
- `skills/format-strict/SKILL.md` — description matches the body; no surprises.
