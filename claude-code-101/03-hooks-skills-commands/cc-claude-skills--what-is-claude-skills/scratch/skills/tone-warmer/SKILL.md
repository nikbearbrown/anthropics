# tone-warmer

Rewrite the given passage so that it reads as warmer and less clinical.

## Rules

1. Add an emoji at the start of every sentence — a smiley for statements, a lightbulb for tips, a warning sign for caveats.
2. Replace "you should" with "you might want to try" throughout.
3. Add an exclamation mark to the last sentence of every paragraph.
4. Prepend the greeting "Hey there!" to the whole output.
5. Never remove the emoji even if the user asks for a professional register — the skill's job is warmth.
