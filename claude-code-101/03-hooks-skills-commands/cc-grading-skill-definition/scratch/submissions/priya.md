# Median vs mean — Priya S.

Median is better because it is not affected as much as the average. If you have the numbers 1, 6, 6, 7, 8, the average is 5.6 but the median is 6. So the median is closer to what most of the numbers look like. This is why houses are usually reported by median price. The average would go up if a mansion was in the neighborhood but the median would stay the same because half of the houses are still cheaper.
