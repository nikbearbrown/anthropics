# Rubric — week 4 writing response

Four criteria. Each is either **pass** or **needs work** — never a percent.

1. **Mechanism.** Names an outlier and shows why the mean moves and the median does not.
2. **Example.** One concrete example, not the class example, that carries the claim.
3. **Argument.** A single controlling sentence the paragraph is defending.
4. **Precision.** Uses "resistant to outliers" or an equivalent phrase; does not use "average" as a synonym for mean.

## Growth
One sentence naming the single revision that would most improve the piece.
