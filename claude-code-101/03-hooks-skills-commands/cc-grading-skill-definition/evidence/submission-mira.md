# Median vs mean — Mira O.

The mean gets dragged around by outliers; the median doesn't. If a class of ten students has salaries at graduation of $45k, $48k, $50k, $52k, $54k, $55k, $58k, $60k, $62k, and one lands at $400k, the mean jumps to $88.4k. The median barely moves — from $54.5k to $54.5k. A number that describes almost nobody in the room is a worse summary than a number that describes the middle person, which is the point. So report the median when a single big value is doing all the pulling.
