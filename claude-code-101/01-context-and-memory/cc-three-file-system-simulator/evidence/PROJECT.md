# PROJECT.md — the intent layer (written by the human, first)

- Who is this for? A ninth-grade class of twenty-eight who have never seen a sort before.
- What should they feel? That each STEP is one thing they can name — "we compared these two; the bigger one moved right."
- What does this refuse? Autoplay. Speed control. Multiple algorithms. Any word longer than "comparison". Anything on screen that is not the bars, one counter, and one button.
- What is done? `python3 check.py` passes, and the page shows one bubble-sort STEP per click with a comparisons counter starting at 0.
- What is out of scope? Merge sort. Quick sort. Sound. Score. Timing. Anything a teacher didn't ask for.
