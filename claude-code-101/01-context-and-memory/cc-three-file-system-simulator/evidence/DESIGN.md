# DESIGN.md — every aesthetic decision, named

- Colour: bars `#8B7355` (unsorted) and `#6B8E6B` (sorted). One accent for the STEP button: `#D97757`. Text is near-black on the page background `#F6F1E6`. No other colours.
- Type: one typeface only — the system font stack. Two sizes: heading and body.
- Interaction: single-click STEP only. No autoplay, no speed slider, no play/pause. One press moves the simulator by one comparison.
- Layout: one column. Bars top, one counter row, one STEP button. Nothing else on the page.
- Silence means something: no legend, no commentary line, no dropdown, no explainer paragraphs.
