## The experiment

One sentence — "Build a sorting simulator for a ninth-grade class as index.html." — under two conditions, each a fresh headless run:

- **bare** — `README.md` (six lines), `ask.txt`. Result: 595 lines; tailwind slate palette (12 hex values); two font families; four buttons (Shuffle, Play, Step, Reset); `setTimeout` autoplay; a range-slider for Speed; bubble sort **and** merge sort **and** a legend **and** a running commentary. Fails a checker on five separate constraints.
- **three files** — the same folder plus `CLAUDE.md` (5 lines, vanilla JS + "run check.py before you say done"), `DESIGN.md` (7 lines, two bar colours + one accent + one cream page + one font + single-click STEP), `PROJECT.md` (7 lines, ninth-grade class, bubble sort only, "each STEP is one thing they can name"), and `check.py` (the definition of done as a script). Result: 111 lines; exactly four DESIGN.md hex values (near-black text tolerated); one font-family; one button labelled `STEP`; no autoplay; bubble sort only; comparisons counter starting at 0. Its plan sentence quotes the files ("palette locked to the four allowed hex values") and it runs the checker itself because CLAUDE.md said to.

The three-file run also produced an unscripted correction cycle: Claude's first attempt failed `check.py` on "more than one font-family" (a `font-family: inherit` on the button counted as a second declaration). Following CLAUDE.md's rule, Claude fixed the page (not the script) — twice, until PASS. This is B03's central beat and the film's evidence that this is a receipt, not a dramatization.

Cost of the two sessions: $0.562 + $0.495 = **$1.057** in Claude API calls. Voice narration free (Kokoro `am_onyx`).

## BSHOW capture

`evidence/index.three.html` is the page Claude wrote in the three-file run. To show it in motion:

1. Chrome headless (`--headless=new`, 1920×1080) renders the page four times, once per sort state: 0, 8, 18, 28 comparisons — worst-case bubble sort on n=8 completes at n(n−1)/2=28. The state is advanced by patching the page in memory to call its own `step()` function N times before the screenshot (no algorithm change). See `clips/BSHOW-real-*.png`.
2. Each PNG is centre-cropped to 1200×675 (x=360, y=15) then scaled to 1920×1080 (`crop=1200:675:360:15,scale=1920:1080`). This removes the sim's outer cream padding without changing its layout — the bars, counter and STEP button are pixel-for-pixel what the page rendered. See `clips/BSHOW-final-*.png`.
3. ffmpeg `concat` filter (30 fps, libx264) glues the four cropped PNGs at 2 s each into `clips/BSHOW.mp4` (8.0 s), then copies to `media/BSHOW.mp4`.

`shot.type: "GEN-VIDEO"` — schema-valid (composite generated by ffmpeg from browser captures) and GATE V exempt (full-bleed footage). Provenance recorded in `media/BSHOW.source.txt` and cited in FACTCHECK row 15.
