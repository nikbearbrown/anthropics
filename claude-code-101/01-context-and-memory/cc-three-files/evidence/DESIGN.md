# DESIGN.md — every aesthetic decision, named

- Tone: plain and calm. No exclamation marks. No emoji. Never the word "welcome".
- Type: one typeface only — the system font stack. Two sizes: heading and body.
- Colour: black text on an off-white page. One accent for the single button: #D97757. Nothing else.
- Layout: one column, 60 characters wide, generous space. No cards, no hero image, no icons.
- Silence means something here: no tagline, no testimonial, no FAQ.
