# BUILD PROMPT — stop-prompting-claude

## Episode concept
The central insight is that prompting is the wrong abstraction. When your context lives in files that Claude reads automatically, you never need to prompt again — the files do it for you. Obsidian is the free tool that makes those files browsable, editable, and beautiful, completing the Second Brain loop: Obsidian updates the brain, Cowork does the building.

Greeting "Konnichiwa" in typing animation. Ask: "Write a LinkedIn post in my voice." Answer preview: "Claude already knows your tone, your rules, your goals — because it read your files first." Sets up the contrast between naive prompting and file-based context. Liam sign-in overlay bottom-left.

The core reframe. Cowork reads .md files before every session. No more 500-word instruction blocks. This is the conceptual foundation for everything that follows.

**B04 — SPARK: "The files go stale." (28–37 s)**

**B05 — SPARK: "Obsidian. It's free." (37–47 s)**
The solution drop. Single app, one action (open folder as vault), instant benefit. The "Edit → Claude knows immediately" line is the key payoff moment.

**B07 — SPARK: "Two apps. One folder." (59–69 s)**
