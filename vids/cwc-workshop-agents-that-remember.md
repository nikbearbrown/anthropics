## cwc-workshop-agents-that-remember

- **Source path:** cwc-workshops/agents-that-remember/
- **Teachable claim:** Two Managed Agents primitives — a memory store (cross-session persistence) and the Dreaming Service (learning from past transcripts) — transform an amnesiac agent into a colleague that improves from its own experience.
- **Suggested builder:** terminal-screencast
- **Suggested channel:** claude-liam
- **Runtime estimate:** medium (5–6 min)

### Visual beats
1. The amnesiac demo: ask agent what you told it thirty seconds ago — it doesn't know
2. Memory store added: same question after adding the memory store — it knows
3. Dreaming Service: the agent consolidates its past transcripts overnight → applies learned patterns in the next session
4. "Goldfish to colleague" arc: the three stages shown as a before/during/after
