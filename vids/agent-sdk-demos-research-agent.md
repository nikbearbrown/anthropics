## agent-sdk-demos-research-agent

- **Source path:** claude-agent-sdk-demos/research-agent/
- **Teachable claim:** A multi-agent research system — orchestrator breaks topic into subtopics, parallel researcher agents search the web, synthesizer assembles the findings — produces a cited comprehensive report while showing real-time subagent activity in the UI.
- **Suggested builder:** terminal-screencast
- **Suggested channel:** claude-liam
- **Runtime estimate:** medium (4–5 min)

### Visual beats
1. Orchestrator spawning parallel researchers: each subtopic handled by a separate agent session — shown in the activity feed
2. Subagent search calls: web search queries scrolling in real-time as researchers work
3. Synthesis: all findings flowing into the final report with citations — the assembly visible
4. Subagent activity tracker: the UI panel showing each agent's status and last action
